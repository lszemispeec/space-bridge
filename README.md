# Space Bridge

A retro pixel-art browser game in TypeScript. It is inspired by the Elektronika IM-09 "Космический мост" handheld from the 1980s.

Cosmonauts jump from the rocket to the rover across a road with craters. You move the bridge plate under each landing. If you miss, the cosmonaut falls into the crater.

## Stack

- Vite, TypeScript, Canvas 2D (320×240, integer scaling)
- Web Audio chiptune (no audio files)
- Keyboard and on-screen touch controls

Status: work in progress.
